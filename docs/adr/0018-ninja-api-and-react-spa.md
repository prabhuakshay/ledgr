# A Django Ninja API behind a React SPA

ledgr is a rebuild of Velora, which rendered Django templates and enhanced them with HTMX and Alpine. ledgr instead serves a JSON API from Django Ninja and a React single-page app (TanStack Router and Query, Tailwind, shadcn-style primitives, types generated from the OpenAPI schema), copying the conventions of the sibling project Nudge. The template stack made rich interactions such as the transaction editor, inline budget edits and charts awkward to build and slow to load, and sharing one stack with Nudge means one set of patterns to maintain. The domain model, the glossary and ADRs 0001 to 0017 carry over unchanged; where an earlier ADR names a template mechanism, such as ADR 0009's template tag library, the same rule applies to its React equivalent. Moving back to server-rendered pages would mean rewriting every screen, so this is not a free swap.
